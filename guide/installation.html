Installation

قاچىلاش

GitHub نەشر بوغچىسىنى قاچىلاڭ ياكى رېپو مەنبەسىنى بىۋاسىتە HTTP ئارقىلىق ئىشلىتىڭ.

بۇ بەتتە
ئالدىن تەييارلىقنەشر بوغچىسىنى قاچىلاشقۇرۇلۇش قورالى بار تۈرقۇرۇلۇش قورالى يوق ئاددىي HTMLقاچىلاشنى تەكشۈرۈشReact بوغچىسىتورسىز بۆلەك قاچىلاش

ئالدىن تەييارلىق

بوغچا بىلەن ئىشلەش ئۈچۈن Node.js 20+ ۋە ئۆز تۈرىڭىزنىڭ بوغچا باشقۇرغۇچىسى لازىم. كۈتۈپخانىنىڭ ئىجرا ۋاقتىدا باشقا JavaScript بوغچىسىغا تايىنىشچانلىقى يوق. تۈرىڭىزدە بار قۇرۇلۇش قورالىنى داۋاملىق ئىشلىتەلەيسىز.

توغرا قاچىلاش ئادرېسى

ھازىرچە يالغۇز npm install @uyghurcommunity/ui نى ئىشلەتمەڭ. تۆۋەندىكى بۇيرۇقلار GitHub دىكى 0.4.0 نەشر ئارخىپىنى قاچىلايدۇ.

نەشر بوغچىسىنى قاچىلاش

npm

npm install https://github.com/UyghurCommunity/uyghur-ui/releases/download/v0.4.0/uyghurcommunity-ui-0.4.0.tgz

pnpm

pnpm add https://github.com/UyghurCommunity/uyghur-ui/releases/download/v0.4.0/uyghurcommunity-ui-0.4.0.tgz

Yarn

yarn add https://github.com/UyghurCommunity/uyghur-ui/releases/download/v0.4.0/uyghurcommunity-ui-0.4.0.tgz

بۇ ئۈچ ئۇسۇلدىن تۈرىڭىزدە ئىشلىتىۋاتقان بىرىنى تاللاڭ. تۈرىڭىزنىڭ قۇلۇپ ھۆججىتىنى ساقلاڭ؛ شۇنداقتا كوماندىدىكى باشقىلارمۇ ئوخشاش بوغچا مەزمۇنىنى قاچىلايدۇ.

قۇرۇلۇش قورالى بار تۈر

تۈرىڭىزنىڭ JavaScript كىرىش ھۆججىتىگە ئۇسلۇب ۋە لازىملىق كونترولنى كىرگۈزۈڭ. CSS نىڭ ئىچىدىكى خەت ھۆججىتىمۇ بىللە يۈكلىنىدۇ.

import '@uyghurcommunity/ui/styles.css';
import { bindDialog, iconSVG } from '@uyghurcommunity/ui';

HTML ياكى رامكا تەركىبىدىكى سىرتقى قاچىغا ug-ui نى قوشۇڭ. ئۇيغۇرچە مەزمۇنغا lang="ug" dir="rtl" بەلگىلەڭ.

<main class="ug-ui" lang="ug" dir="rtl">
  <button class="ug-button" type="button">باشلاڭ</button>
</main>

قۇرۇلۇش قورالى يوق ئاددىي HTML

رېپونى چۈشۈرۈپ، مىسال بېتىڭىزنى ئۇنىڭ تۈپ مۇندەرىجىسىگە قويۇڭ. تۆۋەندىكى يوللار شۇ ئورۇنغا ماس كېلىدۇ؛ بېتىڭىزنى باشقا مۇندەرىجىگە يۆتكىسىڭىز، نىسپىي يوللارنىمۇ تەڭشەڭ.

git clone https://github.com/UyghurCommunity/uyghur-ui.git
cd uyghur-ui
python3 -m http.server 4173 --bind 127.0.0.1
<link rel="stylesheet" href="./src/styles.css">
<script type="module">
  import { iconSVG } from './src/index.js';
  document.getElementById('mark').innerHTML = iconSVG('dutar');
</script>

بۇ قىسقا مىسال ئۈچۈن بېتىڭىزدە <span id="mark"></span> بولۇشى كېرەك. تولۇق ھۆججەتنى تېز باشلاش بۆلىكىدىن كۆچۈرۈڭ. ES module ھۆججەتلىرىنى HTTP ئارقىلىق ئېچىڭ؛ file:// ئارقىلىق ئېچىشقا تايانماڭ.

قاچىلاشنى تەكشۈرۈش

node --input-type=module -e "import { iconNames } from '@uyghurcommunity/ui'; console.log(iconNames.length)"

0.4.0 نەشرىدە نەتىجە 110 بولىدۇ. بۇيرۇق بوغچا تۈرىڭىزنىڭ ئىچىدىن ئىجرا قىلىنسۇن. CSS import خاتالىقى چىقسا، ئۇنى ئاددىي Node ئىچىدە ئەمەس، CSS نى بىر تەرەپ قىلالايدىغان تور تۈرىڭىزنىڭ كىرىش ھۆججىتىدە ئىشلىتىڭ.

React بوغچىسى

npm install https://github.com/UyghurCommunity/uyghur-ui/releases/download/v0.4.0/uyghurcommunity-ui-0.4.0.tgz https://github.com/UyghurCommunity/uyghur-ui/releases/download/v0.4.0/uyghurcommunity-ui-react-0.4.0.tgz
import '@uyghurcommunity/ui/styles.css';
import { Button, Icon, Dialog, Tabs, UyghurInput, Interaction } from '@uyghurcommunity/ui-react';
export function Hello() {
  return <main className="ug-ui" lang="ug" dir="rtl"><Button>باشلاڭ</Button><Icon name="dutar" /></main>;
}

React نى قوللىنىشچان تۈرىڭىز تەمىنلەيدۇ. تەركىبلەرنىڭ props ۋە ھايات دەۋرى ئۈچۈن React بوغچىسىنىڭ README سىنى كۆرۈڭ؛ بىر ئېلېمېنتقا ئىككى كونترولنى بىرگە باغلىماڭ. npm تىزىملىكىگە ئېلان قىلىش ھازىرچە كېچىكتۈرۈلگەن.

تورسىز بۆلەك قاچىلاش

npm install --save-dev https://github.com/UyghurCommunity/uyghur-starters/releases/download/v0.2.0/uyghurcommunity-create-0.2.0.tgz
npx create-uyghur --ui-list
npx create-uyghur --ui combobox --dir examples/new-combobox

CLI 0.2.0 نىڭ تاللاشلىرى: writing-field، dialog، combobox، dropdown، drawer، data-table. --dir ئۈچۈن يېڭى نىسپىي مۇندەرىجە تاللاڭ؛ بۇ قورال يەرلىك قېلىپ ئىشلىتىدۇ، تورغا ئېلان قىلمايدۇ.
