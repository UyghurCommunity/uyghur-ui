FAQ and troubleshooting

Resolve archive installation, fonts, copy failures, SSR and contribution questions.

The registry cannot find the package

npm registry publishing is deferred. Use the complete pinned GitHub archive URL in Installation, inside your own project. Core and React are separate archives; install both when using the React wrappers. Commit your lockfile and verify which release it resolves.

Components look like plain HTML

Confirm that styles.css loaded and the controls are inside ug-ui. A plain browser page needs relative imports or an import map; bare package imports normally belong in a bundler. The quick start assumes its HTML is stored in the checkout root and served over HTTP.

ALKATIP Basma did not load

The font is hosted externally. Check connectivity, your CSP and the font request in browser tools. Tahoma/serif fallbacks keep text visible. Font binaries are not redistributed. An offline deployment needs an approved locally supplied font stylesheet and removal of the original external import.

Copy or download is unavailable

A browser may deny clipboard access. The documentation offers selectable code as a fallback. Interaction examples can also be downloaded as complete HTML containing the controller, CSS and inline cultural artwork; comparison maps are embedded as data SVGs. Fonts still use the separately documented external URLs.

Can I use SSR, React or another framework?

Pure imports, SVG renderers and metadata can be used during server rendering. Bind DOM controllers only after mount and destroy them on real unmount. The separate React package provides lifecycle wrappers. Do not make two systems manage the same event handlers or attributes.

Where does the data go?

Core does not add analytics, authentication, a form service or application storage. Demonstrations use local values. The font stylesheet makes external font requests, links navigate when opened, and any service you add has its own behavior. A send animation is not a delivery API.

Report a problem or contribute

Use the community guide and issue forms. Include reproduction steps, package version, browser and expected/actual results. Cultural naming corrections benefit from a specific source or regional explanation. Never include credentials, private records or a real token in an example.
