Theming

Theming

Create a validated theme, export CSS or JSON, and retain legible Uyghur typography.

Scope CSS tokens

Component colors, radii and typography are controlled through CSS variables. Override tokens on a containing element rather than changing every component rule. Logical spacing keeps the same layout usable in RTL and LTR. Test normal, hover, disabled, error and keyboard-focus states after changing colors.

.my-product {
  --ug-blue:#146650;
  --ug-blue-hover:#0c503e;
  --ug-focus:#146650;
  --ug-radius:14px;
  --ug-font:"ALKATIP Basma",Tahoma,serif;
}

Four reusable presets

The theme workbench offers doppa, atlas, desert and ceramic. Create a theme from a preset, optionally customize accent, radius, fontSize, lineHeight and mode, then export the result. Returned theme objects and their tokens are deeply frozen.

import {createTheme,exportThemeCSS,exportThemeJSON} from '@uyghurcommunity/ui/themes';
const theme=createTheme('doppa');
const css=exportThemeCSS(theme,{selector:'.my-product'});
const json=exportThemeJSON(theme);

The CSS export uses .ug-ui unless you provide a selector. Save it to a stylesheet loaded after the base styles, and apply the same class to your container. The JSON export is a portable record of the preset and tokens; it does not itself apply styles or persist a setting.

Dark mode

Set data-ug-theme="dark" on an ancestor for the built-in dark palette. Remove the attribute to return to default colors. Your application decides how to store a preference. The documentation shell stores only its own theme choice in local storage and tolerates blocked storage.

ALKATIP Basma and fallbacks

The base stylesheet imports font.css, which requests the owner's supplied OnlineWebFonts WOFF2, WOFF and TTF URLs, using font-display:swap. Font binaries are not bundled or covered by the MIT code license. Text remains readable with Tahoma and serif fallbacks when the host is unavailable. For a restrictive content-security policy or an offline deployment, replace the font import with a stylesheet you are entitled to host; changing the font token alone does not remove an existing import.

Typography and spacing

Keep Uyghur words joined rather than splitting letters into animated spans. Give paragraphs sufficient line height, allow wrapping and isolate code in LTR blocks. English documentation retains the same font stack so embedded Uyghur examples can still use Basma. Avoid applying decorative letter spacing to joined Arabic-script text.
