0.4.0 · Application and writing toolkit

This release expands core with Uyghur input support, application controllers, reusable interaction bindings and validated theme exports. It adds a separate React package, an offline component installer workflow, a writing/theme/component Lab, bilingual documentation and contributor resources. Icons remain at 110 outlines and 63 cultural color variants; the sourced maps and their provenance are retained.

New core subpaths are writing, application, interactions and themes. Interaction CSS is exported separately. bindDialog now supports dismissOutside, enabled by default. The React archive is versioned alongside core under the UI release; registry publication remains deferred. The create CLI 0.2 adds local UI templates and safe new-directory creation.

0.3.0 · Color variants and maps

Added 36 cultural themes, reaching 110 outline icons and 63 cultural icons with color variants. Added coloredIconNames, per-icon variants metadata, standalone color SVGs and expanded ZIP archives. Introduced mapSVG, mapMetadata, two map styles and the original Natural Earth source feature. The documented map uses the modern Xinjiang admin-1 polygon, not historical boundary reconstruction.

0.2.0 · Cultural icon collection

Added 24 icons, reaching 74 total and 27 cultural icons when the original doppa, almond and flower motifs are included. Introduced bilingual labels, categories, aliases, iconCatalog, iconCategories and findIcons, along with reproducible full/cultural ZIP downloads.

0.1.0 · Initial toolkit

Introduced CSS components, native dialogs, RTL tabs, form validation, disclosures and plain-text toasts. The first release contained 50 SVG icons, the East Turkistan flag, the ALKATIP Basma font link and TypeScript declarations.

Site changes and pinned packages

The original six motion demonstrations were initially website-only additions after 0.3.0. Version 0.4.0 makes their reusable controllers available through a core interaction subpath. A site update does not automatically change a package already installed in your application. Compare your lockfile and installed package metadata, then update with a pinned archive and retest the flows you use.

Release history: 0.4.0, 0.3.0, 0.2.0 and 0.1.0.
