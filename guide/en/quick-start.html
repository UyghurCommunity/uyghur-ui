Create a complete Uyghur form and accessible native dialog with explicit cleanup.

Your first complete page

Save this as starter.html in a served checkout. Open it through your local HTTP server. The input has a real label, an associated error message and a local result region. The dialog has a name, visible close action and a trigger to restore focus.

<!doctype html>
<html lang="ug" dir="rtl">
<head><meta charset="utf-8"><meta name="viewport" content="width=device-width,initial-scale=1"><title>سالام</title><link rel="stylesheet" href="./src/styles.css"></head>
<body class="ug-ui"><main>
<h1>بىرلىكتە قۇرايلى.</h1>
<form id="hello"><label for="name">ئىسمىڭىز</label><input class="ug-input" id="name" name="name" required minlength="2" dir="auto" aria-describedby="name-error" data-ug-error="name-error"><span id="name-error" class="ug-error"></span><button class="ug-button" type="submit">تەكشۈرۈش</button><p id="result" role="status"></p></form>
<button id="open" type="button" class="ug-button">تەڭشەك</button>
<dialog id="settings" class="ug-dialog" aria-labelledby="title"><h2 id="title" tabindex="-1">تەڭشەك</h2><button type="button" data-ug-close>تاقاش</button></dialog>
<script type="module">
import {bindForm,bindDialog} from './src/index.js';
const form=bindForm(document.getElementById('hello'),{onValid(){document.getElementById('result').textContent='فورما توغرا؛ بۇ يەرلىك سىناق.';}});
const dialog=bindDialog(document.getElementById('settings'),{trigger:document.getElementById('open'),initialFocus:document.getElementById('title')});
window.addEventListener('pagehide',event=>{if(!event.persisted){form.destroy();dialog.destroy();}});
</script></main></body></html>

Exercise the behavior

  1. Submit an empty form. The inline error should appear and focus should reach the invalid input.
  2. Enter two or more characters and submit again. The result remains local.
  3. Open the dialog, navigate with Tab, then press Escape. Focus should return to the trigger.
  4. Repeat using only the keyboard and on a narrow screen.

Switch to package imports

import '@uyghurcommunity/ui/styles.css';
import { bindForm, bindDialog } from '@uyghurcommunity/ui';

Use these imports in your bundler entry and retain the HTML. Replace the sample onValid only when you have a real submission path. Native field validation is useful feedback; validate again on the server before storing or acting on submitted data.

Grow the example

Add application controls, connect Uyghur writing support, or select a theme. Binding methods are lifecycle objects, so keep and destroy them when a client-side view is removed. A BFcache pagehide is not an unmount.
