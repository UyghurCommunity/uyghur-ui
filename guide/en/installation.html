Installation

Installation

Install pinned core and React GitHub release archives, or use the source directly over HTTP.

Requirements

Use Node.js 20 or newer for package and command-line work, plus the package manager already used by your application. The vanilla core has no runtime JavaScript dependencies. CSS requires a bundler that supports CSS imports, or a normal stylesheet link. Native dialog, ES modules and modern CSS require a compatible browser.

Install a pinned release

npm install https://github.com/UyghurCommunity/uyghur-ui/releases/download/v0.4.0/uyghurcommunity-ui-0.4.0.tgz
# Alternatives:
pnpm add https://github.com/UyghurCommunity/uyghur-ui/releases/download/v0.4.0/uyghurcommunity-ui-0.4.0.tgz
yarn add https://github.com/UyghurCommunity/uyghur-ui/releases/download/v0.4.0/uyghurcommunity-ui-0.4.0.tgz

Choose one command, run it inside your project, and commit the resulting lockfile. The bare registry command npm install @uyghurcommunity/ui is not the current distribution method.

import '@uyghurcommunity/ui/styles.css';
import { bindDialog, iconSVG } from '@uyghurcommunity/ui';

React package

npm install https://github.com/UyghurCommunity/uyghur-ui/releases/download/v0.4.0/uyghurcommunity-ui-0.4.0.tgz https://github.com/UyghurCommunity/uyghur-ui/releases/download/v0.4.0/uyghurcommunity-ui-react-0.4.0.tgz
import '@uyghurcommunity/ui/styles.css';
import { Button, Icon, Dialog, Tabs, UyghurInput, Interaction } from '@uyghurcommunity/ui-react';

export function Welcome() {
  return <main className="ug-ui" lang="ug" dir="rtl"><Button>باشلاڭ</Button><Icon name="dutar" /></main>;
}

React is supplied by your application. The wrapper package is separate from the vanilla controllers; use the React package's README for its component props and lifecycle. Do not bind a vanilla controller to an element whose same state is already managed by a wrapper.

Plain HTML without a bundler

git clone https://github.com/UyghurCommunity/uyghur-ui.git
cd uyghur-ui
python3 -m http.server 4173 --bind 127.0.0.1

Put your example in the repository root, link ./src/styles.css, and import ./src/index.js in a module script. Serve ES modules through HTTP. Relative source paths in the quick start assume this directory; adjust them if you move the file.

Offline component installer

npm install --save-dev https://github.com/UyghurCommunity/uyghur-starters/releases/download/v0.2.0/uyghurcommunity-create-0.2.0.tgz
npx create-uyghur --ui-list
npx create-uyghur --ui combobox --dir examples/new-combobox

The create CLI 0.2 supports --ui-list to list available examples, and --ui <id> --dir <relative/new-directory> to create one. IDs are writing-field, dialog, combobox, dropdown, drawer and data-table. It uses local templates; choose a new relative directory and retain the generated notices. It does not publish or deploy your project.

Verify installation

node --input-type=module -e "import { iconNames } from '@uyghurcommunity/ui'; console.log(iconNames.length)"

The result for 0.4.0 is 110. Run this inside the consuming project. A CSS import error in plain Node does not mean the package failed: import styles in the browser application or use a stylesheet link.
