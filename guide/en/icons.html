Cultural objects and motifs

The collection contains 110 outline icons and 63 cultural color variants. Subjects include clothing, crafts, architecture, instruments, food, plants, animals and ornament. Search accepts Uyghur and English names and aliases. These are simplified original interface pictograms, not technical reconstructions of museum objects. The frame drum is Dap; Tambur remains a separate long-necked instrument.

Render and label an icon

import { iconSVG, coloredIconNames, findIcons } from '@uyghurcommunity/ui/icons';
const dutar = iconSVG('dutar', {size:48,label:'دۇتار',variant:'color'});
findIcons('راۋاب'); // ['rawap']
console.log(coloredIconNames.length); // 63

An empty label makes an icon decorative. Give a meaningful standalone icon a label, and give an icon-only button its own action name. Size is an integer from 12–256 and strokeWidth is 0.5–4. Labels are limited to 160 characters. Keep outline icons inline when they must inherit currentColor; an external image does not inherit the surrounding page's color.

Files, categories and downloads

Use @uyghurcommunity/ui/icons/dutar or @uyghurcommunity/ui/icons/color/dutar, without an extension. The catalog is exported as @uyghurcommunity/ui/catalog.json. Filters include all, traditional, music, textiles, architecture, table, garden (Nature), clothing, crafts, motifs and general.

All icons includes 110 outlines and 63 color variants. The cultural collection includes 63 of each. Both archives include the flag, map styles, original map source, metadata, license and notices.

East Turkistan map

The collection names this asset East Turkistan. Its geometry is Natural Earth's Xinjiang admin-1 polygon, CHN-1756 / CN-XJ, layer 5.1.1 from pinned repository release v5.1.2. This is that dataset's modern administrative outline, not a reconstruction of historical boundaries. Dataset description.

import { mapSVG, mapMetadata } from '@uyghurcommunity/ui/maps';
const outline = mapSVG({width:640,label:'شەرقىي تۈركىستان خەرىتىسى'});
const filled = mapSVG({variant:'filled',color:'#559EE2'});
console.log(mapMetadata.source.layerVersion); // '5.1.1'

Both maps preserve all 1,835 vertices, use viewBox 0 0 1024 906 and an equirectangular projection with standard parallel 42°N. North stays up and east stays right; never mirror geography for RTL. Map width is an integer from 64–2048, strokeWidth 0.5–12, and color is currentColor, #RGB or #RRGGBB. Map generation has no font or network dependency.

Download outline SVG, filled SVG, the map ZIP, source GeoJSON or metadata. Made with Natural Earth; the geographic data is public domain.

Flag and source notices

flagSVG({width:180,label:'شەرقىي تۈركىستان بايرىقى'}) renders the East Turkistan flag without mirroring. Width is an integer from 24–1800. The simple geometric flag is public domain; original icon code is MIT. Reference images are not redistributed. See third-party notices for attribution and the separately hosted font.
