Imports and lifecycle

import { bindDialog, bindTabs, bindDisclosure, bindForm, validateForm, showToast, iconSVG, mapSVG } from '@uyghurcommunity/ui';
import { bindUyghurInput } from '@uyghurcommunity/ui/writing';
import { bindCombobox, bindDropdown, bindDrawer, bindDataTable } from '@uyghurcommunity/ui/application';
import { interactionBindings, bindSpotlight, bindTilt, bindSelection, bindSend, bindCompare, bindRipple } from '@uyghurcommunity/ui/interactions';
import { createTheme, exportThemeCSS, exportThemeJSON } from '@uyghurcommunity/ui/themes';

Core imports do not access the document. Bind controllers after elements exist. Keep each returned controller and call destroy() before removing its view; avoid rebinding an already managed element. React wrappers perform this lifecycle in their own package.

Native interface controllers

BindingOptions and return value
bindDialog(dialog, options)trigger, initialFocus and dismissOutside (default true). Returns open(), close(value?) and destroy(). Set dismissOutside:false when outside pointer clicks must not dismiss.
bindDisclosure(button, panel)Returns toggle(), setOpen(boolean), destroy(). Connect aria-controls in the markup.
bindTabs(container)Returns select(tab, focus?) and destroy(). Uses roving focus, Home/End, RTL arrows and vertical orientation.
bindForm(form, options)onValid and messages; validates actual native validity, focuses an invalid field and returns destroy().
validateForm(form, options)Returns field/message errors, with Uyghur defaults.
showToast(region, text, options)duration defaults to 8000 ms; 0 keeps it until dismissed. Returns dismiss()/destroy(). Text is rendered as text.

Uyghur input

bindUyghurInput(root, {onChange(value), maxLength:10000}) adds writing support to the authored field. Its controller exposes getValue(), setValue(value), previewCleanup(options?), applyCleanup(), undoCleanup(), validate() and destroy(). validate returns {valid,message,length,maxLength}; setValue, applyCleanup and undoCleanup return booleans. Preview a cleanup before applying it, and retain the original so a person can undo the change. Treat validation feedback separately from text changes. The writing Lab includes the required markup and a live cleanup preview.

Application controllers

bindCombobox(root, {onChange?}), bindDropdown(root), bindDrawer(root, {initialFocus?, dismissOutside?}) and bindDataTable(root, {pageSize:5}) enhance local markup and return controller objects with destroy(). Combobox exposes open, close, getValue and select(value); dropdown exposes open, close and toggle; drawer exposes open and close; data table exposes getState, setPage(oneBasedPage) and refresh. Use the Lab markup and the shipped application TypeScript definitions for each controller's state methods. Keep data loading, persistence and authorization in your application.

Motion controllers

Import @uyghurcommunity/ui/interactions.css along with the needed binding. Named exports correspond to interactionBindings.spotlight, tilt, selection, send, compare and ripple. Pass a motionAllowed predicate when your application owns pause, visibility or reduced-motion state. Controllers return syncMotion(), reset() and destroy(). The send example is a local animation, not message delivery.

SVG and metadata

iconSVG(name, {size:24,strokeWidth:1.7,label:'',variant:'outline'}) accepts known names. Color is supported for 63 cultural icons; other icons fall back to outline. iconCatalog, coloredIconNames and findIcons(query,{category:'all'}) support selection and search. Labels are escaped. flagSVG keeps a 3:2 ratio; mapSVG uses documented geographic geometry. Read the asset guide for sizes, limits and licenses.
