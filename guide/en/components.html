Choose the correct HTML first

Use a button for an action and an anchor for navigation. A visual class does not change an element's semantics. Keep every interactive control reachable with the keyboard and supply a visible label or accessible name. Scope component styles under ug-ui, with an explicit language and direction for mixed-script applications.

ComponentStyles or binding
Buttonsug-button; secondary, danger, ghost, small and icon modifiers.
Formsug-field, ug-label, ug-input, ug-select, ug-textarea; bindForm and validateForm.
Dialog and drawerNative dialog with bindDialog or the application bindDrawer controller.
Tabs and navigationbindTabs; bindDisclosure for a button and panel.
Cards and feedbackug-card, ug-badge, ug-avatar, ug-alert, ug-progress and showToast.
Application controlsbindCombobox, bindDropdown and bindDataTable.

Labels and native validation

<div class="ug-field">
<label class="ug-label" for="email">ئېلخەت</label>
<input class="ug-input" id="email" name="email" type="email" required dir="ltr" aria-describedby="email-error" data-ug-error="email-error">
<span class="ug-error" id="email-error"></span>
</div>

Group related radio options with fieldset and legend. Keep hints and errors connected using aria-describedby. A placeholder is not a label. Use native disabled controls when the action is unavailable; explain why when the surrounding task needs that information.

Application controls

The component Lab provides the required markup and working examples for a combobox, dropdown, drawer and data table. These controllers progressively enhance existing markup. The data table operates on local rows and supplies sorting, filtering and pagination; it does not silently fetch or persist records. Keep stable row values and label each filter.

A dropdown is a collection of actions, while a combobox is an input with selectable options. Do not substitute one simply because they look similar. Give a drawer a heading and a close action. See the application API for initialization and teardown.

The Lab also composes these primitives into a dashboard sidebar with a table and an article editor with writing assistance, preview and local export. These are optional copyable layouts, not hosted application services. Block styles are exported as @uyghurcommunity/ui/blocks.css and included by the core stylesheet.

React wrappers

The separate @uyghurcommunity/ui-react package exports Button, Icon, Dialog, Tabs, UyghurInput and Interaction. Install its pinned archive alongside core and use the wrapper's documented props. A wrapper owns its associated DOM lifecycle; avoid attaching a second vanilla binding to the same controls.

Compose without fixed widths

ug-row wraps related controls onto another line. ug-columns collapses two columns at narrow widths. Use logical spacing properties, allow long Uyghur text to wrap and test the real labels at mobile sizes. Explore the component gallery for copyable examples.
