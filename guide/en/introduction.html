A foundation for Uyghur interfaces

Uyghur UI combines framework-independent CSS with small JavaScript controllers. Start with real HTML buttons, labels, inputs, dialogs and tables. Add only the behavior your page needs, then keep that controller for teardown. Core modules can be imported during server rendering; bind DOM controllers after their elements exist.

The default Uyghur typeface is ALKATIP Basma. Declare lang="ug" dir="rtl" for Uyghur content and isolate English technical values with bdi or an explicit LTR container. This English guide is LTR; its Uyghur examples retain their own language and direction.

What is included

AreaIncluded
Core componentsButtons, forms, cards, navigation, dialogs, tabs, disclosures and plain-text notifications.
Application controlsCombobox, dropdown, drawer and a paginated data table; explicit controller cleanup.
WritingUyghur input support with validation, a cleanup preview and undo.
Cultural assets110 outline icons, 63 cultural color variants, a flag and sourced map geometry.
Interaction toolsSix motion controllers and their CSS, with reduced-motion support.
Themes and ReactFour theme presets and a separate React package.

Choose a starting point

Use Installation for release archives, then copy the complete quick start. Explore the Lab for writing, themes and application controls; the Interactions gallery contains six working cultural motion demos. Community explains how to contribute fixes, components and translations.

Version 0.4.0 is distributed through GitHub Releases. npm registry publishing remains deferred. Form delivery, application accounts and storage belong to your application. Demonstrations run locally in the browser and do not send messages.
