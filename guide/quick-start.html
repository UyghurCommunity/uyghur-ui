Quick start

تېز باشلاش

بىر تولۇق HTML ھۆججىتى بىلەن بەلگىلىك فورما ۋە فوكۇسنى قايتۇرىدىغان كۆزنەك قۇرۇڭ.

بۇ بەتتە
تۇنجى بېتىڭىزمىسالنى قانداق سىنايمەن؟قاچىلانغان بوغچىغا ماسلاشتۇرۇشكېيىنكى قەدەم

تۇنجى بېتىڭىز

بۇ مىسالنى رېپونىڭ تۈپ مۇندەرىجىسىگە starter.html نامىدا ساقلاڭ. يەرلىك HTTP مۇلازىمېتىرىنى قوزغىتىپ، http://127.0.0.1:4173/starter.html نى ئېچىڭ. بۇ يولدا قۇرۇلۇش قورالى ياكى npm قاچىلاش قەدىمى لازىم ئەمەس.

<!doctype html>
<html lang="ug" dir="rtl">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>مېنىڭ تۇنجى ئۇيغۇرچە بېتىم</title>
  <link rel="stylesheet" href="./src/styles.css">
  <style>main { max-inline-size: 38rem; margin-inline: auto; padding: 2rem; }</style>
</head>
<body class="ug-ui">
  <main>
    <h1>بىرلىكتە قۇرايلى.</h1>
    <form id="hello-form">
      <div class="ug-field">
        <label class="ug-label" for="name">ئىسمىڭىز</label>
        <input class="ug-input" id="name" name="name" required
          minlength="2" maxlength="80" dir="auto"
          aria-describedby="name-help name-error" data-ug-error="name-error">
        <span class="ug-hint" id="name-help">كەم دېگەندە ئىككى ھەرپ كىرگۈزۈڭ.</span>
        <span class="ug-error" id="name-error"></span>
      </div>
      <button class="ug-button" type="submit">تەكشۈرۈش</button>
      <p id="form-result" role="status"></p>
    </form>
    <button class="ug-button ug-button--secondary" id="open-settings"
      type="button">تەڭشەكنى ئېچىش</button>
    <dialog class="ug-dialog" id="settings" aria-labelledby="settings-title">
      <h2 id="settings-title" tabindex="-1">كۆرۈنۈش تەڭشىكى</h2>
      <p>Escape ياكى تاقاش كۇنۇپكىسى بىلەن قايتىڭ.</p>
      <button class="ug-button" type="button" data-ug-close>تاقاش</button>
    </dialog>
  </main>
  <script type="module">
    import { bindDialog, bindForm } from './src/index.js';
    const dialog = bindDialog(document.getElementById('settings'), {
      trigger: document.getElementById('open-settings'),
      initialFocus: document.getElementById('settings-title'),
    });
    const form = bindForm(document.getElementById('hello-form'), {
      onValid() {
        document.getElementById('form-result').textContent =
          'فورما توغرا. بۇ يەرلىك سىناق؛ مەزمۇن ئەۋەتىلمىدى.';
      },
    });
    window.addEventListener('pagehide', (event) => {
      if (!event.persisted) { dialog.destroy(); form.destroy(); }
    });
  </script>
</body>
</html>

مىسالنى قانداق سىنايمەن؟

  1. فورمىنى بوش قالدۇرۇپ تەكشۈرۈڭ؛ خاتالىق تېكىستى كۆرۈنىدۇ ۋە فوكۇس بىرىنچى خاتا رامكىغا بارىدۇ.
  2. ئىككى ياكى ئۇنىڭدىن كۆپ ھەرپ كىرگۈزۈڭ؛ يەرلىك نەتىجە ئۇچۇرى چىقىدۇ.
  3. كۆزنەكنى ئېچىڭ، Tab بىلەن يۆتكىلىڭ ۋە Escape بىلەن تاقاڭ. فوكۇس ئېچىش كۇنۇپكىسىغا قايتسۇن.

قاچىلانغان بوغچىغا ماسلاشتۇرۇش

قۇرۇلۇش قورالى بار تۈرگە كۆچۈرگەندە نىسپىي CSS ئۇلانمىسىنىڭ ئورنىغا تۈرىڭىزنىڭ كىرىش ھۆججىتىدە بوغچا CSS نى import قىلىڭ؛ كونترول import يولىنىمۇ بوغچا نامىغا ئالماشتۇرۇڭ.

import '@uyghurcommunity/ui/styles.css';
import { bindDialog, bindForm } from '@uyghurcommunity/ui';
فورما نەتىجىسى

مىسالدىكى onValid پەقەت ئېكراندىكى يەرلىك ئۇچۇرنى يېڭىلايدۇ. ھەقىقىي ساقلاش ياكى ئەۋەتىش ئۈچۈن ئۆز مۇلازىمېتىرىڭىز ۋە مۇلازىمېتىر تەرەپ تەكشۈرۈشى لازىم.

كېيىنكى قەدەم
