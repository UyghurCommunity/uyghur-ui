FAQ and troubleshooting

كۆپ سورىلىدىغان سوئاللار

قاچىلاش، خەت يۈكلىنىشى، copy، SSR ۋە بۆلەكلەرنىڭ ئادەتتىكى مەسىلىلىرىگە جاۋاب.

بۇ بەتتە
npm بوغچىنى تاپالمىدى، نېمە قىلىمەن؟كۇنۇپكا ئاددىي HTML غا ئوخشايدۇخەت ALKATIP Basma دا كۆرۈنمىدىكۆزنەك ياكى بەتكۈچ ئىشلىمىدىكۆچۈرۈش كۇنۇپكىسى ئىشلىمىدىSSR ياكى React/Vue دا ئىشلىتەمدۇ؟بۇ قورال مەزمۇننى تورغا ئەۋەتەمدۇ؟مەسىلە ياكى تۆھپە قانداق يوللىنىدۇ؟

npm بوغچىنى تاپالمىدى، نېمە قىلىمەن؟

npm تىزىملىكىگە ئېلان قىلىش ھازىرچە كېچىكتۈرۈلگەن. GitHub ئارخىپىنىڭ تولۇق ئادرېسى بار بۇيرۇقنى ئىشلىتىڭ. Node نىڭ 20 ياكى ئۇنىڭدىن يۇقىرى نەشرىنى تاللاپ، بۇيرۇقنى تۈرىڭىزنىڭ ئىچىدە ئىجرا قىلىڭ.

كۇنۇپكا ئاددىي HTML غا ئوخشايدۇ

styles.css نىڭ يۈكلەنگەنلىكىنى ۋە توغرا نىسپىي يولنى تەكشۈرۈڭ. قىسمىڭىزنى ug-ui قاچىسىغا قويۇڭ. قۇرۇلۇش قورالى يوق بەتتە bare package import ئىشلىتىش ئۈچۈن import map ياكى باشقا ھەل قىلىش لازىم؛ ئاددىي مىسالدا ./src/index.js نى ئىشلىتىڭ.

خەت ALKATIP Basma دا كۆرۈنمىدى

خەت سىرتقى OnlineWebFonts ساھىبىدىن يۈكلىنىدۇ. تور ئۇلىنىشى، CSP ۋە خەت تەلىپىنىڭ نەتىجىسىنى تەكشۈرۈڭ. ئۇ يەتمىسە زاپاس خەتتە مەزمۇن يەنىلا كۆرۈنىدۇ. بوغچا خەت binary سىنى ساقلىمايدۇ؛ خەت تاللىشىڭىزنى خەت قوللانمىسىدىكىدەك باشقۇرۇڭ.

كۆزنەك ياكى بەتكۈچ ئىشلىمىدى

DOM ياسالغاندىن كېيىن binding قۇرغانلىقىڭىزنى، dialog نىڭ accessible نامى بارلىقىنى، tab/panel ID باغلىنىشىنىڭ توغرىلىقىنى تەكشۈرۈڭ. ھەر بىر panel قاچا ئىچىدە بولسۇن. Native dialog، ES module ۋە زامانىۋى CSS نى قوللايدىغان توركۆرگۈچ ئىشلىتىڭ؛ كونا توركۆرگۈچكە polyfill بۇ توپلامدا قوشۇلمىغان.

كۆچۈرۈش كۇنۇپكىسى ئىشلىمىدى

توركۆرگۈچ clipboard ھوقۇقىنى چەكلىشى مۇمكىن. كۆرگەزمە ۋە قوللانمىدا ئاددىي تاللاپ كۆچۈرۈش ئۇسۇلىدىن پايدىلىنىڭ؛ SVG نى ھۆججەت قىلىپ چۈشۈرۈشمۇ بار. ئۆز تۈرىڭىزدە clipboard ئەمەلگە ئاشمىسا قولدا كۆچۈرگىلى بولىدىغان تېكىست تەمىنلەڭ.

SSR ياكى React/Vue دا ئىشلىتەمدۇ؟

DOM غا كىرمەيدىغان import، iconSVG، mapSVG ۋە metadata نى مۇلازىمېتىردىمۇ ئىشلىتىشكە بولىدۇ. DOM كونتروللىرىنى client تەرەپتە ئېلېمېنت mount بولغاندىن كېيىن باغلاپ، unmount بولغاندا destroy() قىلىڭ. رامكىنىڭ ئۆزى باشقۇرۇۋاتقان ئوخشاش attribute ۋە event لارنى ئىككى قېتىم باشقۇرماڭ؛ تەييار React/Vue wrapper بۇ نەشرگە قوشۇلمىغان.

بۇ قورال مەزمۇننى تورغا ئەۋەتەمدۇ؟

كۈتۈپخانا ئۆزى فورما مۇلازىمىتى، analytics ياكى ھېسابات API سىنى قوشمايدۇ. ئۇسلۇبنىڭ سىرتقى خەت تەلىپى بار؛ GitHub ئۇلانمىلىرىنى ئېچىش ياكى تۈرىڭىزگە ئۆزىڭىز قوشقان API ئايرىم ھەرىكەت. كۆرسىتىش مىساللىرىدا مەزمۇن يەرلىك بىر تەرەپ قىلىنىدۇ.

مەسىلە ياكى تۆھپە قانداق يوللىنىدۇ؟

GitHub Issues دا قايتا سىناش قەدەملىرى، كۈتكەن ۋە كۆرۈلگەن نەتىجە، نەشر ۋە توركۆرگۈچ ئۇچۇرىنى يېزىڭ. مەدەنىيەت سىنبەلگىسىگە تۈزىتىش تەكلىپ قىلغاندا ئېنىق مەنبە ياكى رايونلۇق ئاتىلىشنى قوشۇڭ. پارول، token ياكى شەخسىي سانلىق مەلۇماتنى مىسالغا قوشماڭ.
