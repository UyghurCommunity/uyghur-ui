ئاساسىي CSS ئۆزگەرگۈچىلىرى

توپلام CSS ئۆزگەرگۈچىلىرىنى ئىشلىتىدۇ. ئۆز CSS ھۆججىتىڭىزنى كۈتۈپخانا ئۇسلۇبىدىن كېيىن يۈكلەپ، ئۆزگەرتىشنى بىر قاچىنىڭ دائىرىسىگە بەلگىلەڭ.

ئۆزگەرگۈچىمەنىسىسۈكۈتتىكى قىممەت
--ug-blueئاساسىي ھەرىكەت رەڭگى#086aa7
--ug-blue-hoverئاساسىي كۇنۇپكا hover رەڭگى#075687
--ug-accentتەكىتلەش رەڭگى#559ee2
--ug-surface · --ug-bgكارتا ۋە بەت تەگلىكى#fff · #f4f7f9
--ug-text · --ug-mutedئاساسىي ۋە ياردەم تېكىست رەڭگى#152d3d · #566b78
--ug-line · --ug-softسىزىق ۋە يېنىك تەگلىك#c9d7df · #e8f3fc
--ug-radiusكونترول يۇمىلاق بۇلۇڭى10px
--ug-focus · --ug-dangerفوكۇس ۋە خاتالىق رەڭگى#126ca4 · #b43137
.my-product {
  --ug-blue: #146650;
  --ug-blue-hover: #0c503e;
  --ug-accent: #2b8a6b;
  --ug-focus: #146650;
  --ug-radius: 14px;
}

قاراڭغۇ كۆرۈنۈش

كۆرۈنمە يۈز قاچىسى ياكى html ئېلېمېنتىغا data-ug-theme="dark" قوشۇڭ. بۇ attribute نى ئېلىۋەتسىڭىز سۈكۈتتىكى رەڭلەرگە قايتىدۇ. تاللاشنى ساقلاشنى تۈرىڭىز باشقۇرىدۇ.

<main class="ug-ui" data-ug-theme="dark" lang="ug" dir="rtl">
  <button class="ug-button" type="button">داۋاملاشتۇرۇش</button>
</main>
document.documentElement.dataset.ugTheme = 'dark';
// Return to the default light palette:
delete document.documentElement.dataset.ugTheme;

ALKATIP Basma ۋە زاپاس خەت

styles.css نىڭ ئىچىدىن font.css يۈكلىنىدۇ. ئۇ ALKATIP Basma نى خوجايىن تەمىنلىگەن OnlineWebFonts ئادرېسلىرىدىن WOFF2، WOFF، TTF تەرتىپىدە سورايدۇ. font-display: swap ئارقىلىق خەت كېلىشتىن بۇرۇن زاپاس خەتتە مەزمۇن كۆرۈنىدۇ؛ خەت binary ھۆججىتى بوغچىغا قوشۇلمىغان.

.my-product {
  --ug-font: "ALKATIP Basma", Tahoma, serif;
}
.my-product .technical-value {
  font-family: ui-monospace, "ALKATIP Basma", monospace;
}

باشقا خەتنى ئىشلىتىش ئۈچۈن ئۇنىڭ توردا ئىشلىتىش ھوقۇقى ۋە يۈكلەش ئۇسۇلىنى تەكشۈرۈپ، ئۆز خەت ئۇسلۇبىڭىزنى تەمىنلەڭ. قاتتىق CSP ياكى سىرتقى تەلەپسىز ئورۇنلاشتۇرۇش ئۈچۈن خەت import تەلىپىنىمۇ ئۆزىڭىزگە ماسلاشتۇرۇشىڭىز كېرەك؛ يالغۇز token نى ئالماشتۇرۇش بار بولغان font import نى ئېلىۋەتمەيدۇ.

بوشلۇق ۋە چوڭلۇق

بارلىق نەرسىگە بىر line-height بەرمەڭ. ئۇيغۇرچە ئوقۇش مەزمۇنىغا يېتەرلىك قۇر ئارىلىقى قالدۇرۇپ، كود ۋە قىسقا تېخنىكىلىق قىممەتنى ئايرىم LTR قاچىدا ساقلاڭ. ئۆزگەرتكەن رەڭلىرىڭىزنى ئادەتتىكى، hover، چەكلەنگەن، خاتا ۋە فوكۇسلانغان ھالەتلەردە قايتا تەكشۈرۈڭ.
