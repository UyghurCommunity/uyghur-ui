بۆلەكلەر

ھەر بىر بۆلەكنىڭ HTML ئۇسلۇبى، JavaScript تەلىپى ۋە بىۋاسىتە سىناق مىسالى.

بۇ بەتتە
لازىملىق بۆلەكنى تاللاڭكۇنۇپكا ۋە ئۇلانمارامكا، تاللاش ۋە گۇرۇپپابۆلەكلەرنى بىرلەشتۈرۈش

لازىملىق بۆلەكنى تاللاڭ

ئۇسلۇب ھۆججىتىنى بىر قېتىم يۈكلەپ، مەزمۇننى ug-ui قاچىسىغا قويۇڭ. كۆرگەزمىدىكى كود كۆچۈرۈش كۇنۇپكىسى HTML، لازىملىق كونترول ۋە تەييار SVG نى بىللە بېرىدۇ.

بۆلەكئاساسىي سىنىپ ياكى كونترولمىسال
كۇنۇپكاug-buttonسىناش
فورماug-field · ug-input · bindFormسىناش
سۆزلىشىش كۆزنىكىug-dialog · bindDialogسىناش
بەتكۈچug-tabs · bindTabsسىناش
يولباشلاشug-nav · bindDisclosureسىناش
كارتا ۋە بەلگەug-card · ug-badge · ug-avatarسىناش
يىغىلىدىغان مەزمۇنug-accordion · detailsسىناش
ئۇقتۇرۇش ۋە جەريانug-alert · ug-progress · showToastسىناش

كۇنۇپكا ۋە ئۇلانما

بەت ئىچىدە ھەرىكەت ئىجرا قىلغاندا button، باشقا ئادرېسقا بارغاندا a ئىشلىتىڭ. شەكىل سىنىپى ئېلېمېنتنىڭ ئەسلى مەنىسىنى ئالماشتۇرمايدۇ.

<div class="ug-row">
  <button class="ug-button" type="button">ساقلاش</button>
  <button class="ug-button ug-button--secondary" type="button">بىكار قىلىش</button>
  <button class="ug-button ug-button--danger" type="button">ئۆچۈرۈش</button>
  <a class="ug-button ug-button--ghost" href="./installation.html">قاچىلاش</a>
</div>

ug-button--small كىچىك كۆرۈنۈش ئۈچۈن، ug-button--icon پەقەت سىنبەلگىلىك كۇنۇپكا ئۈچۈن. كېيىنكىسىگە چوقۇم aria-label ياكى كۆرۈنىدىغان نام بېرىڭ.

رامكا، تاللاش ۋە گۇرۇپپا

رامكىنىڭ بەلگىسىنى label for بىلەن باغلاڭ. رادىئو تاللاشلىرى ئۈچۈن fieldset ۋە legend نى ئىشلىتىڭ. خاتالىقنى رەڭدىن باشقا تېكىست بىلەنمۇ كۆرسىتىڭ.

<div class="ug-field">
  <label class="ug-label" for="email">ئېلخەت</label>
  <input class="ug-input" id="email" name="email" type="email" required
    dir="ltr" aria-describedby="email-error" data-ug-error="email-error">
  <span class="ug-error" id="email-error"></span>
</div>

تاللاش ۋە ئۇزۇن تېكىست ئۈچۈن ug-select، ug-textarea بار. تاللاش بەلگىسى ۋە ئالماشتۇرغۇچقا ug-check، ug-switch ئىشلىتىڭ. ئۇلارنىڭ ئىچىدە ھەقىقىي input بولىدۇ.

بۆلەكلەرنى بىرلەشتۈرۈش

<div class="ug-columns">
  <article class="ug-card">
    <span class="ug-badge">ئوچۇق مەنبە</span>
    <h2>بىر ئىدىيە، كۆپ ئىمكانىيەت.</h2>
    <p>تۈرىڭىزنىڭ ھەقىقىي مەزمۇنىنى بۇ يەرگە قويۇڭ.</p>
  </article>
  <aside class="ug-alert"><p>داۋاملاشتۇرۇشتىن بۇرۇن مەزمۇننى تەكشۈرۈڭ.</p></aside>
</div>

ug-row بۆلەكلەرنى بىر قۇرغا تىزىپ، تار ئېكراندا كېيىنكى قۇرغا يۆتكەيدۇ. ug-columns ئىككى ستوننى كىچىك ئېكراندا بىر ستونغا ئايلاندۇرىدۇ. كۆپرەك كونترول لازىم بولسا JavaScript API نى كۆرۈڭ.
