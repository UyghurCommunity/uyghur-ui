نەشر خاتىرىسى

ئېلان قىلىنغان بوغچا نەشرلىرى ۋە ھەر بىر نەشرگە كىرگەن ھەقىقىي ئۆزگىرىشلەر.

بۇ بەتتە
0.3.0 · ئىككى نۇسخىلىق مىراس توپلىمى ۋە خەرىتە0.2.0 · مەدەنىيەت سىنبەلگىلىرى0.1.0 · تۇنجى UI توپلىمىقوللانما ۋە بوغچا نەشرى

0.3.0 · ئىككى نۇسخىلىق مىراس توپلىمى ۋە خەرىتە

36 يېڭى مەدەنىيەت تېمىسى قوشۇلۇپ، توپلام 110 سىنبەلگىگە يەتتى. 63 مەدەنىيەت سىنبەلگىسىنىڭ ھەممىسىگە رەڭلىك نۇسخا قوشۇلدى؛ بۇرۇنقى سىزىقلىق سۈكۈتتىكى كۆرۈنۈش ۋە import يوللىرى ساقلانغان.

  • ئەنئەنىۋى كىيىم، ساپال، زىبۇزىننەت، سۇرناي، بىناكارلىق، مەنزىرە، چاي سايمانلىرى، ھايۋان ۋە بېزەك نەقىشلىرى.
  • iconSVG(name, { variant }) تاللىشى، coloredIconNames ۋە ھەر سىنبەلگىنىڭ variants metadata سى.
  • مۇستەقىل رەڭلىك SVG ھۆججەتلىرى ۋە ئىككى نۇسخىنى ئۆز ئىچىگە ئالغان ZIP ئارخىپلىرى.
  • شەرقىي تۈركىستاننىڭ سىزىقلىق ۋە تولدۇرۇلغان SVG خەرىتىسى، mapSVG، mapMetadata، ئەسلى GeoJSON ۋە مەنبە خاتىرىسى.
  • Natural Earth نىڭ نەشرى بەلگىلەنگەن شىنجاڭ admin-1 پولىگونى، ئاممىۋى مۈلۈك ئىجازەتنامىسى ۋە projection ئۇچۇرى.

0.3.0 نەشر ۋە چۈشۈرۈش ھۆججەتلىرى.

0.2.0 · مەدەنىيەت سىنبەلگىلىرى

24 يېڭى SVG سىنبەلگە قوشۇلدى. بۇ نەشر 74 سىنبەلگىنى ئۆز ئىچىگە ئالاتتى؛ مەدەنىيەت توپلىمىدا بۇرۇنقى دوپپا، بادام ۋە گۈل نەقىشلىرىنى قوشقاندا 27 سىنبەلگە بار ئىدى.

  • دۇتار، تەمبۈر، راۋاپ، غېجەك، ساتار ۋە داپ.
  • ئەتلەس، گىلەم، كەشتە، توقۇش دەستگاھى ۋە ئۇرچۇق.
  • ئايۋان، راۋاق، ئويما ئىشىك ۋە تورلۇق دېرىزە.
  • نان، سامسا، پولۇ، لەغمەن، چەينەك، پىيالە، ئانار، ئۈزۈم ۋە ئۆرۈك.
  • ئىككى تىللىق نام، تۈرلەر ۋە يىپ ئۇچلىرى؛ iconCatalog، iconCategories، findIcons export لىرى.
  • تولۇق ۋە مەدەنىيەت توپلىمى ئۈچۈن ئايرىم ZIP، JSON metadata ۋە قايتا ھاسىل قىلغىلى بولىدىغان asset قۇرۇلۇشى.

0.2.0 نەشر ۋە چۈشۈرۈش ھۆججەتلىرى.

0.1.0 · تۇنجى UI توپلىمى

CSS بۆلەكلىرى، يەرلىك كۆزنەك، RTL بەتكۈچ، فورما تەكشۈرۈش، disclosure ۋە ئاددىي تېكىست ئۇقتۇرۇشى ئېلان قىلىندى. تۇنجى توپلامدا 50 SVG سىنبەلگە، شەرقىي تۈركىستان بايرىقى، ALKATIP Basma خەت ئۇلانمىسى ۋە TypeScript ئېنىقلىمىلىرى بار ئىدى.

0.1.0 نەشر ئارخىپى ئۆز پېتى ساقلانغان. يېڭى تۈر ئۈچۈن 0.3.0 قاچىلاش ئۇسۇلىنى تاللاڭ.

قوللانما ۋە بوغچا نەشرى

بۇ قوللانما ھازىرقى 0.3.0 API نى چۈشەندۈرىدۇ. تور بېتىدىكى يېڭى قوللانما ياكى لايىھە ئۆزگىرىشى ھەمىشە يېڭى بوغچا نەشرى دېگەنلىك ئەمەس. قاچىلانغان بوغچا نەشرىنى ئۆز تۈرىڭىزنىڭ قۇلۇپ ھۆججىتى ۋە package ئۇچۇرى بىلەن سېلىشتۇرۇڭ.

نەشرنى يېڭىلاش

نەشرى بەلگىلەنگەن GitHub ئارخىپ يولىنى ئىشلىتىڭ. يېڭى بوغچا قاچىلاشتىن بۇرۇن ئۆز تۈرىڭىزدىكى فورما، كۆزنەك، بەتكۈچ ۋە سىنبەلگە import لىرىنى تەكشۈرۈڭ.
