Introduction

ئۇيغۇرچە قۇرۇشنى باشلاڭ

ئۇيغۇرچە كۆرۈنمە يۈز، مەدەنىيەتتىن ئىلھام ئالغان سىنبەلگىلەر ۋە ئاددىي تور تېخنىكىسى بىر يەردە.

بۇ بەتتە
بىر بۆلەكتىن پۈتۈن بىر كۆرۈنمە يۈزگىچەتوپلام ئىچىدە نېمىلەر بار؟قايسى يەردىن باشلايمەن؟جانلىق UI نى سىناڭتۈرىڭىزدە نېمىنى ئۆزىڭىز بېكىتىسىز؟

بىر بۆلەكتىن پۈتۈن بىر كۆرۈنمە يۈزگىچە

ئۇيغۇرچە UI بولسا ئۇيغۇرچە تور بەت قۇرۇشقا ئىشلىتىدىغان CSS بۆلەكلىرى، كىچىك JavaScript كونتروللىرى ۋە SVG سىنبەلگىلەر توپلىمى. بەتنىڭ تىلى ۋە يۆنىلىشىنى ئۆزىڭىز بەلگىلەپ، لازىملىق بۆلەكنى تۈرىڭىزگە قوشىسىز.

كۇنۇپكا، رامكا، كارتا ۋە يىغىلىدىغان مەزمۇن يەرلىك HTML ئۈستىگە قۇرۇلغان. كۆزنەك، بەتكۈچ، تىزىملىك ۋە ئۇقتۇرۇشقا ئايرىم كونترول بار. بۇ شەكىل ئاددىي تور بەتتىمۇ، رامكا ئىشلىتىدىغان تۈردىمۇ بىرلا بۆلەك ئۇسلۇبىنى ساقلايدۇ.

توپلام ئىچىدە نېمىلەر بار؟

بۆلەكئىشلىتىش ئورنى
كۇنۇپكا ۋە فورماكونترول، ئېنىق بەلگە، ئۇيغۇرچە خاتالىق ئۇچۇرى ۋە ياردەم تېكىستى.
كۆزنەك ۋە بەتكۈچيەرلىك modal كۆزنەك، فوكۇس قايتۇرۇش ۋە RTL ئوق كۇنۇپكىلىرى.
كارتا، بەلگە ۋە تىزىملىكمەزمۇننى گۇرۇپپىلاش، ھالەتنى كۆرسىتىش ۋە يولباشلاش.
110 SVG سىنبەلگە63 مەدەنىيەت سىنبەلگىسىنىڭ سىزىقلىق ۋە رەڭلىك نۇسخىسى، ئىككى تىللىق نام ۋە ئىزدەش يىپ ئۇچلىرى.
بايراق ۋە خەرىتەشەرقىي تۈركىستان بايرىقى، سىزىقلىق ۋە تولدۇرۇلغان خەرىتە، ئېنىق سانلىق مەلۇمات مەنبەسى.
6 جانلىق مىسالكەشتە نۇرى، دوپپا چوڭقۇرلۇقى، ئەتلەس تاللاش، خەت جانلاندۇرۇش، خەرىتە سېلىشتۇرۇش ۋە نەقىش دولقۇنى.
ALKATIP Basmaسىرتقى ئادرېستىن يۈكلىنىدىغان خەت نۇسخىسى ۋە زاپاس خەتلەر.

قايسى يەردىن باشلايمەن؟

  1. قاچىلاش بۆلىكىدىن تۈرىڭىزگە ماس ئۇسۇلنى تاللاڭ.
  2. تېز باشلاش مىسالى بىلەن ھەقىقىي كۆزنەك ۋە فورما قۇرۇڭ.
  3. بۆلەكلەر ۋە سىنبەلگىلەر قوللانمىسىدىن لازىملىقىنى تېپىڭ.
  4. رەڭ ۋە خەتنى خاسلاشتۇرۇڭ، ئاندىن كۇنۇپكا تاختىسى بىلەن سىناڭ.
ھازىرقى نەشر · 0.3.0

قاچىلاش بوغچىسى GitHub Releases دا بار. npm تىزىملىكىگە ئېلان قىلىش ھازىرچە كېچىكتۈرۈلگەن؛ قوللانمىدىكى نەشرى بەلگىلەنگەن ئادرېسنى ئىشلىتىڭ.

جانلىق UI نى سىناڭ

جانلىق تەسىرلەر كۆرگەزمىسىدىن 6 ئەسلى مىسالنى سىناڭ. ھەر مىسالدا HTML، CSS ۋە JavaScript نى تولۇق كۆچۈرۈش ياكى بىر HTML ھۆججىتى قىلىپ چۈشۈرۈش بار. كۆرگەزمىنىڭ ئۈستىدىكى كۇنۇپكا ھەرىكەتنى توختىتىدۇ؛ سىستېمىنىڭ ھەرىكەتنى ئازايتىش تەڭشىكىگە ئەمەل قىلىنىدۇ. تاللاش، كۇنۇپكا ۋە سۈرگۈچلەر كۇنۇپكا تاختىسى بىلەنمۇ ئىشلەيدۇ.

بۇلار تور كۆرگەزمىسىنىڭ مۇستەقىل مىساللىرى؛ 0.3.0 بوغچىسىغا يېڭى npm export قوشۇلمىغان. «كودىنى كۆرۈش ۋە ئىشلىتىش» نى ئېچىپ، تولۇق HTML نى كۆچۈرۈپ demo.html نامىدا ساقلاڭ ياكى بىۋاسىتە چۈشۈرۈڭ. خەت جانلاندۇرۇش مىسالى پەقەت يەرلىك سىناق، ئۇچۇر ئەۋەتمەيدۇ. خەرىتە مىسالى چۈشۈرۈلگەن HTML غا ھەر ئىككى SVG نى ئۆز ئىچىگە ئالىدۇ.

تۈرىڭىزدە نېمىنى ئۆزىڭىز بېكىتىسىز؟

كۈتۈپخانا تور مۇلازىمىتى، ئىشلەتكۈچى ھېسابى ياكى سانلىق مەلۇمات ساقلاشنى قوشمايدۇ. فورما نەتىجىسىنى قەيەرگە ئەۋەتىش، قايسى سانلىق مەلۇماتنى ساقلاش ۋە مەزمۇن ئىجازەتنامىسىنى قانداق كۆرسىتىشنى تۈرىڭىز بەلگىلەيدۇ. كۆرگەزمىدىكى فورما پەقەت يەرلىك سىناق.

كود ۋە ئەسلى سىنبەلگە سىزىقلىرى MIT ئىجازەتنامىسىدە. Natural Earth خەرىتە سانلىق مەلۇماتى ئاممىۋى مۈلۈك. خەت، بايراق، خەرىتە ۋە كۆرۈنۈش پايدىلىنىش مەنبەلىرىنى مەنبە خاتىرىسىدىن كۆرۈڭ.
