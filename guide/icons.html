سىنبەلگىلەر ۋە مەدەنىيەت توپلىمى

74 SVG سىنبەلگە، 27 مەدەنىيەت بەلگىسى، ئۇيغۇرچە ئىزدەش ۋە مۇستەقىل ھۆججەتلەر.

بۇ بەتتە
ئۆز لايىھەڭىزگە بىر مەنىلىك بەلگەJavaScript بىلەن SVG ھاسىل قىلىشنام ۋە تۈر بويىچە ئىزدەشمۇستەقىل SVG ۋە JSONرەڭ ۋە يۆنىلىش

ئۆز لايىھەڭىزگە بىر مەنىلىك بەلگە

0.2.0 نەشرىدە 74 ئەسلى SVG سىنبەلگە بار؛ بۇنىڭ 27 سى مەدەنىيەت توپلىمىغا كىرىدۇ. بۇ نەشر 24 يېڭى سىزىق قوشتى. دۇتار، راۋاپ، ساتار، ئەتلەس، توقۇش دەستگاھى، ئايۋان، نان ۋە چاي سايمانلىرىنى كۆرگەزمىدىن تاللاپ سىناڭ.

بۇلار رەقەملىك كۆرۈنمە يۈز ئۈچۈن ئەسلىدىن سىزىلغان ئاددىي مەدەنىيەت پىكتوگراممىلىرى. رايونغا قاراپ شەكىل ۋە ئاتىلىش ئۆزگىرىدۇ؛ بىر تارىخىي بۇيۇمنىڭ قۇرۇلۇش سىزىقى دەپ ئىشلەتمەڭ. سۈرەت ۋە مەزمۇننىڭ پايدىلىنىش مەنبەلىرى مەنبە خاتىرىسىدە بار.

JavaScript بىلەن SVG ھاسىل قىلىش

import { iconSVG, flagSVG } from '@uyghurcommunity/ui';

const dutar = iconSVG('dutar', { size: 48, label: 'دۇتار' });
const decorative = iconSVG('flower', { size: 24 });
const flag = flagSVG({ width: 180, label: 'شەرقىي تۈركىستان بايرىقى' });

document.getElementById('instrument').innerHTML = dutar;

ئاخىرقى قۇردىكى قاچىڭىز <span id="instrument"></span> بولسۇن. كۈتۈپخانا مەلۇم سىنبەلگە نامىنىلا قوبۇل قىلىپ، label نى escape قىلىدۇ. باشقا مەنبەدىن كەلگەن خالىغان HTML نى بۇ ئۇسۇلدا كىرگۈزمەڭ.

مەنىسى بار يالغۇز سىنبەلگىگە ئۇيغۇرچە label بېرىڭ؛ ئۇنىڭغا role="img" قوشۇلىدۇ. بەلگە بوش بولسا سىنبەلگە بېزەك سۈپىتىدە aria-hidden="true" بولىدۇ. ئىچىدە سىنبەلگە بار كۇنۇپكىنىڭ ئۆزىگە نام بېرىشنىمۇ ئۇنتۇماڭ.

نام ۋە تۈر بويىچە ئىزدەش

import { findIcons, iconCatalog, iconCategories } from '@uyghurcommunity/ui';

findIcons('راۋاب'); // ['rawap']
findIcons('ikat'); // ['atlas']
findIcons('', { category: 'music' }); // six instrument names

const details = iconCatalog.find((icon) => icon.name === 'dutar');
console.log(details.ug, details.en, details.category);
تۈر نامىمەزمۇن
all74 سىنبەلگىنىڭ ھەممىسى.
traditional27 مەدەنىيەت سىنبەلگىسى ۋە نەقىش.
music · textiles · architectureسازلار، توقۇمىچىلىق/نەقىش ۋە بىناكارلىق.
table · garden · generalداستىخان، باغ ۋە ئادەتتىكى كۆرۈنمە يۈز سىنبەلگىلىرى.

ئىزدەش ئۇيغۇرچە نام، ئىنگلىزچە نام ۋە يىپ ئۇچلىرىنى ئۆز ئىچىگە ئالىدۇ. تۈر ۋە سوئال بىللە سۈزۈلىدۇ؛ مەسىلەن ساز نامىنى داستىخان تۈرىدە ئىزدىگەندە بوش نەتىجە چىقىشى نورمال.

مۇستەقىل SVG ۋە JSON

  • مەدەنىيەت SVG توپلىمى — 27 سىنبەلگە ۋە بايراق.
  • تولۇق SVG توپلىمى — 74 سىنبەلگە ۋە بايراق.
  • ئىككى تىللىق JSON — نام، تۈر ۋە ئىزدەش يىپ ئۇچلىرى.

قاچىلانغان بوغچىدىكى ھۆججەت تارماق يوللىرى:

@uyghurcommunity/ui/icons/dutar
@uyghurcommunity/ui/flags/east-turkistan.svg
@uyghurcommunity/ui/catalog.json

سىنبەلگە تارماق يولىغا .svg قوشۇلمايدۇ. رېپودىكى ھەقىقىي ھۆججەت يولى بولسا assets/icons/dutar.svg. بوغچا يولىنى static asset URL غا ئايلاندۇرۇش ئۇسۇلى تۈرىڭىزنىڭ قۇرۇلۇش قورالىغا باغلىق؛ ھۆججەتنى ئۆز public مۇندەرىجىڭىزگە كۆچۈرۈپ، ئادەتتىكى img بىلەنمۇ كۆرسىتەلەيسىز.

رەڭ ۋە يۆنىلىش

<span class="instrument" id="instrument"></span>
<style>
  .instrument { color: #086aa7; }
</style>

سىنبەلگە سىزىقى currentColor غا ئەگىشىدۇ؛ سىرتقى img ھۆججىتى ئىچىدىكى رەڭ بولسا بەتنىڭ color قىممىتىگە ئۆزلۈكىدىن ۋارىسلىق قىلمايدۇ. رەڭنى خاسلاشتۇرۇشقا inline SVG قولاي. SVG لار RTL دا ئۆزلۈكىدىن ئەينەككە ئايلاندۇرۇلمايدۇ؛ ھەرىكەت مەنىسىگە ماس ئوقنى تاللاڭ. بايراقنىڭ ئاي ۋە يۇلتۇز شەكلىمۇ ئەينەككە ئايلاندۇرۇلمايدۇ.
