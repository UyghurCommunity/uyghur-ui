Icons and cultural collection

سىنبەلگىلەر ۋە مەدەنىيەت توپلىمى

110 SVG سىنبەلگە، 63 مەدەنىيەت بەلگىسىنىڭ رەڭلىك نۇسخىسى، بايراق ۋە مەنبەسى ئېنىق خەرىتە.

بۇ بەتتە
ئۆز لايىھەڭىزگە بىر مەنىلىك بەلگەJavaScript بىلەن SVG ھاسىل قىلىشنام ۋە تۈر بويىچە ئىزدەشمۇستەقىل SVG ۋە JSONسىزىقلىق ۋە رەڭلىك نۇسخاشەرقىي تۈركىستان خەرىتىسى

ئۆز لايىھەڭىزگە بىر مەنىلىك بەلگە

0.4.0 نەشرىدە 110 ئەسلى SVG سىنبەلگە بار؛ بۇنىڭ 63 ى مەدەنىيەت توپلىمىغا كىرىدۇ ۋە سىزىقلىق، رەڭلىك ئىككى نۇسخىنى تەمىنلەيدۇ. 0.3.0 دە 36 يېڭى تېما قوشۇلغان: دوپپا، ئەنئەنىۋى كىيىم، ساز، ساپال، بىناكارلىق، مەنزىرە ۋە گۈل نەقىشلىرىنى كۆرگەزمىدىن تاللاپ سىناڭ.

بۇلار رەقەملىك كۆرۈنمە يۈز ئۈچۈن ئەسلىدىن سىزىلغان ئاددىي مەدەنىيەت پىكتوگراممىلىرى. رايونغا قاراپ شەكىل ۋە ئاتىلىش ئۆزگىرىدۇ. ئىشلەتكۈچى تەمىنلىگەن ئىككى مەدەنىيەت تاختىسى تېما تاللاشقا ئىلھام بولدى؛ ئۇلاردىكى سۈرەتلەر بوغچىغا كۆچۈرۈلمىدى. چەمبەر شەكىللىك ئۇرما ساز داپ دەپ ئاتالدى؛ تەمبۈر بولسا ئايرىم ئۇزۇن بويۇنلۇق چالغۇ سۈپىتىدە ساقلانغان. مەنبە ۋە ئاتىلىش خاتىرىلىرى مەنبە خاتىرىسىدە بار.

JavaScript بىلەن SVG ھاسىل قىلىش

import { iconSVG, flagSVG } from '@uyghurcommunity/ui';

const dutar = iconSVG('dutar', { size: 48, label: 'دۇتار' });
const colorfulDutar = iconSVG('dutar', { size: 64, variant: 'color', label: 'دۇتار' });
const decorative = iconSVG('flower', { size: 24 });
const flag = flagSVG({ width: 180, label: 'شەرقىي تۈركىستان بايرىقى' });

document.getElementById('instrument').innerHTML = dutar;

ئاخىرقى قۇردىكى قاچىڭىز <span id="instrument"></span> بولسۇن. كۈتۈپخانا مەلۇم سىنبەلگە نامىنىلا قوبۇل قىلىپ، label نى escape قىلىدۇ. باشقا مەنبەدىن كەلگەن خالىغان HTML نى بۇ ئۇسۇلدا كىرگۈزمەڭ.

مەنىسى بار يالغۇز سىنبەلگىگە ئۇيغۇرچە label بېرىڭ؛ ئۇنىڭغا role="img" قوشۇلىدۇ. بەلگە بوش بولسا سىنبەلگە بېزەك سۈپىتىدە aria-hidden="true" بولىدۇ. ئىچىدە سىنبەلگە بار كۇنۇپكىنىڭ ئۆزىگە نام بېرىشنىمۇ ئۇنتۇماڭ.

نام ۋە تۈر بويىچە ئىزدەش

import { findIcons, iconCatalog, iconCategories, coloredIconNames } from '@uyghurcommunity/ui';

findIcons('راۋاب'); // ['rawap']
findIcons('ikat'); // matching cultural names
findIcons('', { category: 'music' }); // seven instrument names

const details = iconCatalog.find((icon) => icon.name === 'dutar');
console.log(details.ug, details.en, details.category, details.variants);
console.log(coloredIconNames.includes('dutar')); // true

ئىزدەش ئۇيغۇرچە نام، ئىنگلىزچە نام ۋە يىپ ئۇچلىرىنى ئۆز ئىچىگە ئالىدۇ. تۈر ۋە سوئال بىللە سۈزۈلىدۇ؛ مەسىلەن ساز نامىنى داستىخان تۈرىدە ئىزدىگەندە بوش نەتىجە چىقىشى نورمال.

مۇستەقىل SVG ۋە JSON

  • مەدەنىيەت SVG توپلىمى — 63 سىزىقلىق ۋە 63 رەڭلىك سىنبەلگە.
  • تولۇق SVG توپلىمى — 110 سىزىقلىق ۋە 63 رەڭلىك سىنبەلگە.
  • ئىككى تىللىق JSON — نام، تۈر، نۇسخا ۋە ئىزدەش يىپ ئۇچلىرى.

ئىككى SVG ئارخىپىغا بايراق، ئىككى خەرىتە، خەرىتە مەنبەسى ۋە metadata، ئىجازەتنامە ۋە مەنبە خاتىرىسىمۇ قوشۇلغان.

سىنبەلگە تارماق يولىغا .svg قوشۇلمايدۇ. رېپودىكى ھەقىقىي ھۆججەت يولى بولسا assets/icons/dutar.svg. بوغچا يولىنى static asset URL غا ئايلاندۇرۇش ئۇسۇلى تۈرىڭىزنىڭ قۇرۇلۇش قورالىغا باغلىق؛ ھۆججەتنى ئۆز public مۇندەرىجىڭىزگە كۆچۈرۈپ، ئادەتتىكى img بىلەنمۇ كۆرسىتەلەيسىز.

سىزىقلىق ۋە رەڭلىك نۇسخا

import { iconSVG, coloredIconNames } from '@uyghurcommunity/ui/icons';

iconSVG('ceramic-vase', { variant: 'outline', size: 64 });
iconSVG('ceramic-vase', { variant: 'color', size: 64 });
iconSVG('search', { variant: 'color' }); // outline fallback
console.log(coloredIconNames.length); // 63

سۈكۈتتىكى نۇسخا outline. 63 مەدەنىيەت سىنبەلگىسىدە color نۇسخىسى بار؛ قالغان 47 ئادەتتىكى UI سىنبەلگىسىدە رەڭلىك نۇسخا سورالسا سىزىقلىق نۇسخىسى قايتىدۇ. iconCatalog نىڭ variants مەيدانى ياكى coloredIconNames بىلەن قوللاشنى تەكشۈرەلەيسىز.

<span class="instrument" id="instrument"></span>
<style>
  .instrument { color: #086aa7; }
</style>

سىزىقلىق سىنبەلگە currentColor غا ئەگىشىدۇ؛ رەڭلىك نۇسخا ئۆزىنىڭ بېكىتىلگەن رەڭ تاختىسىنى ئىشلىتىدۇ. سىرتقى img ھۆججىتى ئىچىدىكى رەڭ بەتنىڭ color قىممىتىگە ئۆزلۈكىدىن ۋارىسلىق قىلمايدۇ. SVG لار RTL دا ئۆزلۈكىدىن ئەينەككە ئايلاندۇرۇلمايدۇ؛ ھەرىكەت مەنىسىگە ماس ئوقنى تاللاڭ. بايراقنىڭ ئاي ۋە يۇلتۇز شەكلىمۇ ئەينەككە ئايلاندۇرۇلمايدۇ.

شەرقىي تۈركىستان خەرىتىسى

خەرىتە كۆرگەزمىسىدە سىزىقلىق ۋە تولدۇرۇلغان ئىككى نۇسخا بار. بۇ توپلامدىكى «شەرقىي تۈركىستان» خەرىتىسى Natural Earth 1:10,000,000 Admin 1 سانلىق مەلۇماتىدىكى شىنجاڭ مەمۇرىي رايون پولىگونىنى ئىشلىتىدۇ: CHN-1756 / CN-XJ، layer 5.1.1، repository release v5.1.2. بۇ مەنبەدىكى زامانىۋى مەمۇرىي سىزىق؛ تارىخىي چېگرالارنى قايتا قۇرغان خەرىتە ئەمەس.

import { mapSVG, mapMetadata } from '@uyghurcommunity/ui/maps';

const outline = mapSVG({ width: 640, variant: 'outline',
  label: 'شەرقىي تۈركىستان خەرىتىسى' });
const filled = mapSVG({ width: 640, variant: 'filled', color: '#559EE2',
  strokeWidth: 4, label: 'شەرقىي تۈركىستان خەرىتىسى' });
console.log(mapMetadata.source.layerVersion); // '5.1.1'
console.log(mapMetadata.projection.viewBox); // '0 0 1024 906'

mapSVG() نىڭ سۈكۈتتىكى كەڭلىكى 640، نۇسخىسى outline، رەڭگى currentColor، سىزىق قېلىنلىقى 4؛ ئۇيغۇرچە خەرىتە نامى بار. كەڭلىك پۈتۈن سان 64–2048، سىزىق قېلىنلىقى 0.5–12 بولسۇن. رەڭ قىممىتى currentColor، #RGB ياكى #RRGGBB؛ label ئەڭ كۆپ 160 ھەرپ. خەرىتە ھاسىل قىلىش DOM، خەت ھۆججىتى ياكى تور تەلىپىگە تايانمايدۇ.

ھەر ئىككى نۇسخا 0 0 1024 906 viewBox ۋە 42°N ئۆلچەملىك پاراللېللىق equirectangular projection نى ئىشلىتىدۇ. ئەسلىدىكى 1,835 نۇقتىنىڭ ھەممىسى ساقلانغان؛ ئاددىيلاشتۇرۇش قوللىنىلمىغان. شىمال يۇقىرىدا، شەرق ئوڭدا تۇرىدۇ؛ RTL ئۈچۈن خەرىتىنى ئەينەككە ئايلاندۇرماڭ.

  • سىزىقلىق SVG ۋە تولدۇرۇلغان SVG.
  • خەرىتە ZIP توپلىمى.
  • ئەسلى GeoJSON، metadata ۋە مەنبە.
