# Local React application

From this directory run `npm install`, then `npm run dev`. Local `file:` dependencies point to the adapter and core checkouts. The example uses React 18; the adapter also supports React 19. `npm run build` produces the static application. No backend is connected.

Try ordinary typing and the virtual keyboard, preview/apply/undo Unicode cleanup, the controlled dialog and RTL tabs, and all six interactions. The shared pause switch and system reduced-motion preferences apply to the interactions.

When using this example outside the source repository, replace both local `file:` dependencies with the matching v0.4.0 core and React GitHub release archive URLs documented in the adapter README. Font binaries are not included; ALKATIP Basma uses the supplied external font URLs.
