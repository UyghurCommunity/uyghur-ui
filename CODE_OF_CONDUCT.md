# Community conduct · ھەمكارلىق قائىدىسى

بىر-بىرىمىزگە ھۆرمەت قىلىپ، تېخنىكىلىق مەسىلە ۋە ئېنىق دەلىلگە دىققەت قىلايلى. ئۇيغۇرچە ۋە باشقا تىللاردا سوئال سوراش، تۈزىتىش ۋە ئۆگىنىشكە ئورۇن بار.

This project welcomes people contributing code, language knowledge, cultural context and testing. Discuss ideas and behavior respectfully. Disagree with a proposal using concrete reasons; accept corrections and give others space to revise their work.

Harassment, threats, discriminatory abuse, doxxing, sexual harassment and sharing another person's private information are not acceptable. Do not use project issues to target a person or group. Keep discussion relevant to the contribution and avoid repeated unwanted contact.

Maintainers may edit or remove harmful content, close disruptive discussions, or restrict participation when necessary. Apply the same standards fairly to maintainers and contributors. Explain moderation decisions when that can be done without exposing someone else's private information.

For a concern, contact the repository maintainers through an available GitHub maintainer contact channel. Avoid posting private details publicly. For threats or abuse on GitHub, its reporting tools are also available. This project does not promise a private reporting channel that it has not established.

These expectations apply to repository discussions, issues, pull requests and project spaces maintained by UyghurCommunity.
