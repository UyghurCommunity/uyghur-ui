COMMUNITY / BUILD TOGETHER

بىرلىكتە، تېخىمۇ ياخشى قۇرايلى.

ئۇيغۇرچە UI بولسا UyghurCommunity نىڭ ئوچۇق مەنبە قورالى. كود، مەدەنىيەت ئاتىلىشى، تەرجىمە ياكى ھەقىقىي ئىشلىتىش سىنىقى بىلەن تۆھپە قوشالايسىز.

Contribute code, cultural naming corrections, translation and accessibility checks. These are community-maintained examples, not a list of external adopters or endorsements.

تۆھپە قوشۇش يولىنى تاللاڭ

خاتالىقنى قايتا سىناش

كۈتكەن ۋە كۆرۈلگەن نەتىجە، قەدەم، نەشر، توركۆرگۈچ ۋە كىچىك مىسالنى قوشۇڭ.

خاتالىق دوكلاتى ↗

بۆلەك ياكى سىنبەلگە

قانداق مەسىلىنى ھەل قىلىدىغانلىقىنى ۋە كۇنۇپكا تاختىسى ھەرىكىتىنى چۈشەندۈرۈڭ. مەدەنىيەت شەكلى ئۈچۈن مەنبە ياكى رايونلۇق ئاتىلىشنى قوشۇڭ.

تەكلىپ يوللاش ↗

ئۇيغۇرچە ۋە English

بەت ئادرېسى، ھازىرقى جۈملە ۋە تەكلىپ قىلغان تۈزىتىشنى يېزىڭ. ئىككى تىلدىكى قوللانمىنى بىرگە يېڭىلاڭ.

تىل تۈزىتىشى ↗

تۈزىتىشنى تەكشۈرگىلى بولسۇن

  1. تۆھپە قوللانمىسى ۋە ھەمكارلىق قائىدىسىنى ئوقۇڭ.
  2. كىچىك، ئېنىق مەسىلىدىن باشلاڭ؛ ئۆزگەرتىش سەۋەبىنى چۈشەندۈرۈڭ.
  3. كۇنۇپكا تاختىسى، RTL/LTR، تار ئېكران ۋە ھەرىكەتنى ئازايتىشنى سىناڭ.
  4. npm run check، npm test ۋە قايتا ھاسىل قىلىش تەكشۈرۈشىنى ئىجرا قىلىڭ.
  5. مەنبە ۋە ئىجازەتنامە خاتىرىسىنى ساقلاپ، PR غا نەتىجە ۋە سىناق ئۇچۇرىنى قوشۇڭ.

بۇ ئۇلانمىلار GitHub نىڭ يېڭى issue جەدۋىلىنى ئاچىدۇ؛ بۇ بەت ئۆزى ئۇچۇر ئەۋەتمەيدۇ. پارول، token ياكى شەخسىي خاتىرىلەرنى مىسالغا قوشماڭ.
